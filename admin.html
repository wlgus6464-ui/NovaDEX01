GitHub 연결 설정

저장하려면 GitHub 비밀 키가 필요합니다. 이 키는 이 컴퓨터의 이 브라우저 안에만 저장되고, GitHub 에 저장할 때만 쓰입니다.

GitHub 비밀 키 · github_pat_ 로 시작합니다
비밀 키 만드는 법 (처음 한 번만)
  1. GitHub 에 로그인한 상태에서 비밀 키 만들기 화면을 엽니다.
  2. Token name 칸에 NovaDEX 관리자 라고 적습니다.
  3. Expiration 에서 기간을 고릅니다 (예: 1년). 기간이 끝나면 새로 만들어서 여기에 다시 넣으면 됩니다.
  4. Repository access 에서 Only select repositories 를 누르고 NovaDEX01 을 고릅니다.
  5. Permissions 에서 Contents 를 Read and write 로 바꿉니다. (Add permissions 버튼이 보이면 눌러서 Contents 를 고릅니다)
  6. 맨 아래 초록 버튼 Generate token 을 누르고, 나온 키를 복사해서 위 칸에 붙여넣습니다. 이 키는 다시 볼 수 없으니 바로 붙여넣어 주세요.
